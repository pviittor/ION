TERMOS DE USO E POLÍTICA DE PRIVACIDADE

1. INFORMAÇÕES GERAIS

Este documento estabelece os Termos de Uso e a Política de Privacidade do aplicativo Aplicativo Ion, em conformidade com a Lei Geral de Proteção de Dados (LGPD - Lei nº 13.709/2018) e demais legislações aplicáveis.

2. COLETA E TRATAMENTO DE DADOS PESSOAIS

 2.1 Dados Coletados
   Coletamos os seguintes dados pessoais:
   - Dados de identificação: nome, e-mail
   - Dados de acesso: senha (criptografada)
   - Dados de configuração: credenciais de banco de dados (criptografadas)

 2.2 Finalidades do Tratamento
   Seus dados pessoais são tratados para:
   - Criar e gerenciar sua conta de usuário
   - Fornecer acesso aos serviços do aplicativo
   - Conectar-se aos seus bancos de dados conforme configurado
   - Melhorar a experiência do usuário

3. COMPARTILHAMENTO DE DADOS

 3.1 Terceiros
   Seus dados podem ser compartilhados com:
   - Vanna.AI: Para processamento de consultas de IA (conforme configuração `allow_llm_to_see_data`)
   - Provedores de infraestrutura: Para hospedagem e manutenção do serviço

 3.2 Transferência Internacional
    Alguns dados podem ser transferidos para outros países, sempre com as devidas salvaguardas de proteção.

4. SEGURANÇA DOS DADOS
   Implementamos medidas técnicas e organizacionais para proteger seus dados:
   - Criptografia de senhas com bcrypt
   - Criptografia de credenciais sensíveis com AES-256-CBC
   - Controle de acesso baseado em autenticação JWT

5. SEUS DIREITOS COMO TITULAR
   Conforme a LGPD, você tem direito a:
   - Confirmação e acesso: Saber se tratamos seus dados e acessá-los
   - Correção: Corrigir dados incompletos, inexatos ou desatualizados
   - Anonimização, bloqueio ou eliminação: De dados desnecessários ou tratados em desconformidade
   - Portabilidade: Receber seus dados em formato estruturado
   - Informação sobre compartilhamento: Saber com quem compartilhamos seus dados
